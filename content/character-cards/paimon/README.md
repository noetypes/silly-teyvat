# Paimon card

Paimon.json is the editable V2 source. Paimon.png is the importable native character PNG with matching chara (V2) and ccv3 (V3) metadata. Paimon.md is a readable review copy. sources.json records research and the approved portrait hash.

The card has a detailed description and voice guide, five original greetings, six example exchanges and seven contextual character-book entries. It is set at the very start of the game: Paimon has just been pulled out of a whirlpool in Starfell Lake, every greeting shows that first meeting, and she knows nothing about {{user}} or any other character until the chat tells her. It uses an NPC companion role, no assigned combat element, and custom model scale 50, below the Small Female baseline of 72.

The PNG uses the approved neutral without any pixel editing; only character metadata is embedded using SillyTavern's native writer. The 22 Paimon sprites live in the separate art/sprites/2026-10-27-paimon-venti-mika run and are installed into Paimon's character folder. Official Art/neutral.png preserves user attachment 3 as the primary original art reference.
