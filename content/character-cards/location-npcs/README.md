# Location NPC cards

These are SillyTavern character card V2 JSON files; import each through Character Management. The original greetings and portrayals are fan writing, with each card’s Genshin Impact Wiki reference in creator notes. No portrait artwork or sprites are included. The bundled character home catalog assigns imported cards by exact name when no user placement already exists, subject to the resident cap.

Story-era encounters are intentional: Arama, Babel, Jeht, Lyris, Jakob and Rene do not all coexist as present-day residents. Their cards state the chosen era or dreamlike premise. Araja appears in dream Vanarana; Xavier, Valdis and Egle use the relevant post-quest placements. NPC knowledge and user identity are not presumed from the Traveler’s game dialogue.

Aybak is the named Caravan Ribat Eremite selected from the location’s wiki roster. Anselm represents the Favonius expedition; additional unnamed personnel are not invented as individual characters.

Plate and Whistle are dogs, based on the quest dialogue reproduced by HoYoDex. Mayskaya and Knyazev use the available NPC index and station guide; their individual Fandom pages could not be verified. The cards record these limitations and additional sources.
