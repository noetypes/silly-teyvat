# Silly Teyvat 0.65a release verification

Prepared 2026-11-14 with game data 1.84.0. The source release commit includes all
pending agents' changes, Mitya/Valeriy gift and starting Trust defaults, shared
outfit voices, revised location defaults, updated UI art, and the approved Glupov
background. The game-data release includes the revised cards and lorebook,
companion clips and portable configuration.

## Published content

- 275 character cards, 2,484 sprites, 959 uploads and the two bundled personas.
- The uncompressed game-data ZIP is 2,141,816,332 bytes (43 download parts).
- 121 pending generated PNG sprites were converted to WebP: 172,290,222 bytes
  became 25,996,090 bytes. Alpha values are identical; minimum measured PSNR is
  39.7 dB. No generated sprite was left as PNG by the conversion run.
- The 208 PNG sprites retained in the export are Official Art references.
  Character-card PNG containers, personas and art-run source files retain their
  original formats. [Conversion record](../../art/sprites/2026-11-14-webp-installation/manifest.json).
- The new Glupov background is lossless WebP, preserving the approved PNG's RGB
  pixels. The original screenshot and generated PNG remain in the art run/data
  pack. [Approval record](../../art/location-backgrounds/2026-11-14-glupov/manifest.json).

## Validation

Changed JavaScript and Python syntax passed. Node checks passed for sprite files,
Trust/gifts/scenes, game-data updates, share packaging, location coordinate
migration, music and starter scenes. Browser checks passed for starter-catalog
upgrades, converted sprites and wardrobe loading; the live preview passed 319
Trust, 16 background, 83 media and 104 wardrobe/canvas checks. The converted-sprite
browser test timed out once against the live server and passed in the isolated
preview. An early preview runner waited for a root that the test fixture hides;
the suites passed when invoked directly in the live preview.

The export and first-run configuration were checked to contain only Aether and
Lumine as bundled personas. Private connection selections and signatures are
excluded by the exporter and release builder. Source/media integrity checks and
release-manifest tests passed before distribution packaging.
