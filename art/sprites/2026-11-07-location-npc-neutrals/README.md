# Location NPC neutral candidates

Forty-two original neutral sprite candidates, one for each existing card in `character-cards/location-npcs`. These were generated with the built-in `image_gen.imagegen` tool using one online in-game model or character reference per candidate, as requested. The exact prompt, source page and image URL, source and output hashes, raw output path, file dimensions and pending approval state are in `run.json`. The reference files are preserved unaltered.

Open `review.html` to browse the candidates or download `location-npc-neutral-candidates.zip` for the individual PNGs. All 42 PNGs have alpha channels; this technical check is not visual approval. None of these candidates has been approved or installed. The project workflow requires explicit approval of each exact neutral before its expressions can be generated.

Rene uses a labeled HoYoLAB lineup; his individual wiki image could not be retrieved. Granny Ruoxin's HoYoWiki image was cross-checked with the separately saved named in-game screenshot. Lyris uses the water apparition depicted in the wiki image; Plate and Whistle use their dog models.
