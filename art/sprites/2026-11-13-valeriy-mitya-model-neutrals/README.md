Fresh 2026-11-13 run using the user's attached in-game models, one screenshot as the sole image reference for each neutral. These references explicitly replace the default official portrait source for this run. Earlier generated artwork was not used as a reference and remains preserved.

Open `review.html` to compare the screenshots, new neutral candidates, genuine TCG style references and revised TCG candidates. `candidates/<Character>/neutral-v001.png` contains the new sprites. Both await explicit approval per exact file/hash before any expressions. No character cards, extension code, personas or live installation were changed in this run.

`run.json` records the user request, reference authorization, exact tool arguments, source and output hashes, original generation locations and pending approval. Exact prompts and argument JSONs are in `prompts/`. Original generated bytes are preserved in `raw/`. All images were made with built-in `image_gen.imagegen`; no framing transform was applied to the neutrals. Technical checks only verified PNG decoding, dimensions, alpha and hashes.
