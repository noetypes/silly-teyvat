# Xilonen: ten-sprite set

The exact neutral-v002 approved by the user on 2026-11-05 is included unchanged as `sprites/Xilonen/neutral.png`. Each of the nine expressions was generated independently from that approved neutral as the sole image reference, with its own emotion-specific pose and acting prompt.

The user approved all ten sprites on 2026-11-05. They were installed into the live Xilonen character folder, with replaced files backed up and all ten installed hashes verified. See `installation-2026-11-05.json`. The earlier complete ZIP preserves its original pre-installation provenance snapshot. The built-in image generator did not expose or return a model ID, quality setting, or complexity setting.

## Files

- `sprites/Xilonen/`: ten individual transparent PNGs.
- `previews/`: full-body and face review grids, transparent without baked labels.
- `prompts/Xilonen/`: nine exact expression prompts.
- `raw/Xilonen/`: unaltered copies of the nine returned expression images.
- `references/Xilonen/approved-neutral.png`: sole reference used for expressions.
- `sources/Xilonen/`: original neutral model and official-art sources, neutral prompts, generation and approval record. These original sources were not expression inputs.
- `run.json`: exact tool arguments, outputs, approval, hashes, dimensions and preview transforms.
- `archives/xilonen-ten-sprite-set.zip`: ten sprite PNGs only.
- `archives/xilonen-ten-sprite-complete.zip`: all sprites, sources, prompts, raw outputs, previews and provenance.
