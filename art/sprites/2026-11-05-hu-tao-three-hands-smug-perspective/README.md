# Hu Tao — three hand revisions and smug pupil perspective

The approved ivory-tinted love-1 and desire-1 PNGs have been installed in Hu Tao's live sprite folder. The previous two files are backed up under installation-backup/, with source/destination hashes and proof that every other live file remained unchanged in heart-installation.json.

Four new candidates await user review and have not been installed. Confusion, desire and excitement were independently regenerated with the built-in image tool from approved neutral v008 plus the authorized model and portrait. They use new, simpler hand gestures and ordinary five-petal blossom pupils. Exact prompts, actual arguments and unchanged raw outputs are recorded.

Smug is a pupil-only Python perspective adjustment under the existing pupil-compositing authorization. Each eye has its own rotation, shear, compression and visibility mask based on the original iris. The prior patch's local background was restored from the same asset's pre-patch version. Every decoded pixel outside the two recorded previous pupil rectangles remains identical to the reported candidate; the alpha channel is unchanged everywhere. No full sprite generation was used for smug.

Review order left to right: confusion, desire, excitement, smug. previews/full-body.png and previews/faces.png contain all four. previews/smug-eyes-before-after.png shows the reported pupils above the new candidate below. Previews are transparent and unlabeled; exact crop/resize transforms are in run.json. User visual approval is pending. No general autonomous visual QA or repair loop was performed.

archives/revisions.zip contains the four individual PNG candidates. archives/complete-artwork.zip contains the complete run including references, prompts, raw outputs, sources, pupil transforms/masks, installation record and backups.
