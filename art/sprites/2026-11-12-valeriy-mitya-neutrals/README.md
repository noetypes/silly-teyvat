# Valeriy and Mitya neutral candidates

Two unofficial neutral sprites generated with the built-in image generation tool, each using only its original official transparent portrait as an image reference. Open `review.html` to see the official references, neutral candidates and separately generated TCG cards, and to download the character cards.

The current neutral candidates await the user's explicit approval. No expressions were generated and nothing was installed. Technical checks record PNG decoding, dimensions and alpha only; they are not visual approval. `run.json` preserves exact prompts, actual arguments, original output locations and hashes. `raw/` preserves original output bytes. References and downloaded source provenance are linked through `content/character-cards/snezhnaya-2026-11-12/sources.json`.

Media follows the repository's external data pack layout and is linked back here. TCG cards use official wish art and genuine TCG style references, independently of these unapproved neutral candidates.
