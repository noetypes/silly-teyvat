# Paimon, Venti and Mika sprite packs

46 saved transparent PNGs: Paimon and Venti have 22 each; Mika currently has only the approved neutral and confusion, with 20 expressions pending. The three approved neutrals are unchanged. No incomplete Mika sprite sheet has been created. Generated with built-in image_gen. Each expression independently uses its primary official portrait and exact approved neutral. Rejected neutral candidates and expressions are never image inputs. Paimon uses the approved v005, Venti v001 and Mika v002. User attachment 1 is excluded.

Paimon has a custom tiny floating build, smaller than Small Female, with fuller rounded thighs and open-hand gestures. Venti and Mika use their approved petite Medium Male builds. Acting and poses change with emotion. Paimon's affection and anticipation are wholesome friendship, treats and adventure. The -1 love/desire variants use heart pupils with both eyes open: white for Paimon's blue-violet irises, pale mint-teal for Venti, pale ice-blue for Mika. Ordinary expressions retain ordinary pupils.

The user is the visual reviewer. Only file format, alpha-channel presence, dimensions, hashes, source lineage and archive integrity were checked. No generated output was visually inspected, rejected or automatically repaired by the agent.

Individual PNGs are unchanged tool outputs. Transparent sprite sheets use 512x840 cells in a five-column, five-row grid, row-major order below. Unused last-row cells are transparent. Full previews show full bodies; closer previews use a fixed upper-body crop for easier user review. Neither presentation transform changes the individual sprites.

Order, left-to-right and top-to-bottom:
1. neutral, annoyance, smug, confusion, love
2. excitement, joy, fear, pride, desire
3. anger, grief, sadness, disgust, disappointment
4. relief, admiration, gratitude, embarrassment, caring
5. love-1, desire-1

Paimon.zip and Venti.zip each contain 22 active images, sheets, exact prompts and per-character manifest. Mika-partial.zip contains the two saved images and all prepared prompts, explicitly marked incomplete. completed-packs-and-mika-partial.zip contains these saved images plus official source references, approval records and workflow instructions. raw-generations.zip retains raw outputs and historical neutral attempts for provenance; those historical attempts are not current delivery sprites.

The packs have not been installed into live SillyTavern. Installation is separate from this artwork request and can be done directly in the character folders without a browser when requested.
