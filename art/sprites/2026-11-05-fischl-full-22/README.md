# Fischl: full 22-sprite set

The exact neutral-v003 approved by the user on 2026-11-05 is included unchanged as `sprites/Fischl/neutral.png`. Each of the 21 expressions was generated independently with that approved neutral as the sole image reference and an individual emotion-specific pose and acting prompt.

The expressions are candidates for user review. No installation into live SillyTavern was requested or performed. The built-in tool did not expose or return the model ID, quality or complexity setting.

## Generation notes

The image service rejected the initial desire and embarrassment outputs. The revised requests succeeded: desire depicts gentle hopeful anticipation of a wished-for adventure, and embarrassment depicts an awkward moment during a grand introduction. All original and revised prompts and the actual failure messages are preserved. The desire heart alternate uses the same innocent anticipation direction.

The heart alternates request a pale lime-green heart-shaped pupil within the retained green iris of the visible right eye. Her covered left eye remains covered by its eyepatch. These are prompt instructions; visual review belongs to the user.
