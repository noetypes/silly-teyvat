# Starter background refresh

Provenance records that arrived with the initial repository import (27 October 2026). They used to sit in the
extension folder and shipped to players, although nothing in the game reads them.

- `background-refresh.json`: the review of 40 starter waypoint backgrounds, with the old and new source of each
  of the 24 that were replaced.
- `svetloledovka-cleanup.json`: the edit that produced `assets/world-locations/svetloledovka.png` from a
  HoYoLAB map screenshot, with its prompt and review.
