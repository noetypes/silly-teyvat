# Ten character TCG card candidates

Ten unofficial card illustrations created with the built-in image generation tool from official character splash art and distinct genuine TCG card references. They are candidates for user review. Open `review.html` or `contact-sheet.jpg` to compare them. `generation.json` records the exact prompts and reference paths.

`raw/` preserves original outputs. `trimmed/` contains the same RGB pixels with the official TCG alpha outline applied by `tools/trim-card-corners.py`; `trim-report.json` records hashes and verifies transparent corners. These cards have not been installed.
