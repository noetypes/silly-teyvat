# Valeriy and Mitya TCG artwork candidates

Two unofficial Genius Invokation-style card illustrations made with built-in `image_gen.imagegen`. Each uses the character's official wish art for identity and a genuine TCG card for style and framing (Tartaglia for Valeriy, Lisa for Mitya). These are illustrations without combat stats or a new rules implementation.

`raw/` preserves original output. `trimmed/` adds the official TCG alpha outline with `tools/trim-card-corners.py`, preserving every RGB pixel; `trimmed/trim-report.json` records the checks. `generation.json` contains actual tool arguments, exact prompts, references and output hashes. Candidates await user review and have not been installed.
