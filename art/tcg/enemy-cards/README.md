# Enemy TCG card candidates

Eight existing makeshift, wiki-icon cards were replaced with one-pass original illustrations generated by the built-in `image_gen.imagegen` tool. Each used the installed enemy neutral sprite and a genuine enemy TCG card as references. All eight await user review. Open `review.html` for the gallery; `run.json` records exact prompts, file names and SHA-256 hashes. No sprite artwork was changed.

The comparison source is the [Genshin Impact Wiki TCG card gallery](https://genshin-impact.fandom.com/wiki/Genius_Invokation_TCG/Gallery/Cards); the eight replaced types do not appear there. The installed cards and battle kits are fan interpretations, not official Genshin Impact TCG cards.

The inventory covered all 104 enemy entries in `assets/character-properties.json`: 94 appear in the project’s saved enemy/boss TCG research, Fatui Cryo Cicin Mage and Fatui Pyro Agent have their own verified Wiki character-card pages, and the remaining eight were the icon-based cards listed in `drawn-enemies.json` before this replacement.
