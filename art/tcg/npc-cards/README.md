# NPC TCG cards

Forty-six NPC TCG character card illustrations generated with the built-in `image_gen.imagegen` tool, one pass per character. Adel was explicitly accepted by the user; the other candidates await the user’s review. `review.html` presents the full set. `run.json` records each exact prompt and the appearance and TCG style references. The location-NPC appearance references are unapproved neutral candidates and are used here only as image references; this does not approve or generate sprite expressions.
